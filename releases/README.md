# 发布包

## 本地多模态助手 · 轻量版（Windows x64）

**文件**：`本地多模态助手-轻量版-Windows-x64.zip`
**体积**：约 91 MB（解压后约 208 MB，409 个文件）

---

### 与完整版的区别

| 功能 | 轻量版 | 完整版 |
|------|:------:|:------:|
| 多轮对话（流式输出） | ✅ | ✅ |
| 图片理解（点击上传 / 拖拽 / Ctrl+V 粘贴） | ✅ | ✅ |
| 实时时间感知（问"现在几点"可答） | ✅ | ✅ |
| Agent 工具链（记忆 / 知识库 / 文件 / 联网） | ✅ | ✅ |
| 文生图 / 图片微改 | ❌ | ✅ |
| 体积 | 91 MB | 约 11 GB |

轻量版不包含 `torch`、`diffusers` 与随包分发的 SD 模型（合计约 10.6 GB），因此体积小、便于分发。
文生图相关接口在轻量版中会返回"缺少依赖"提示，**不影响其余全部功能**。

> 后端对 `torch` 采用函数内延迟导入，所以缺少该依赖不会影响程序启动。

---

### 使用步骤

1. **解压** zip 到任意目录（建议路径不含空格与中文以外的特殊字符）
2. **安装 Ollama**：前往 https://ollama.com 下载安装（或 `winget install Ollama.Ollama`）
3. **拉取模型**：在终端执行
   ```bash
   ollama pull qwen3-vl:8b
   ```
   （约 6.1 GB，只需一次）
4. **双击 `本地多模态助手.exe`** 即可，程序会自动弹出独立桌面窗口（非浏览器）

> 🔒 完全本地离线运行，数据不出本机。
> 首次启动需数十秒（服务初始化 + 模型加载）；启动失败时会弹窗提示原因，不会静默闪退。

### 想用文生图？

轻量版不含文生图依赖。如需该功能，请从源码运行或使用完整版构建：

```bash
pip install -r requirements.txt          # 含 torch / diffusers
py -3 run.py                             # 源码运行
py -3 -m PyInstaller "build/本地多模态助手.spec" --noconfirm   # 完整版打包
```
