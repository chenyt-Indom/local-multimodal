| 文件 | 体积 | 说明 |
|------|------|------|

## 🎤 语音输入（唤醒词「西派西派」）

**开启方式**：点界面输入框左侧的 **🎤** 按钮 → 说「**西派西派**」唤醒 → 直接说内容 → **停顿 2 秒自动发送**。

- 唤醒后识别文字会**实时填入输入框**，你可以看到识别过程
- 停顿 2 秒（无说话声）即自动发送，无需点按钮
- 全程**离线识别**，音频不离开本机
- 再次点击 🎤 可关闭监听

**语音模型安装**（使用语音功能必做）：

1. 下载 `asr-model-zh-14M-int8.zip`
2. 解压后得到 `asr_model` 文件夹
3. 把它放到**主程序目录下的 `_internal` 文件夹里**，最终结构：

```
本地多模态助手/
├── 本地多模态助手.exe
└── _internal/
    └── asr_model/
        └── sherpa-onnx-streaming-zipformer-zh-14M-2023-02-23/
            ├── encoder-epoch-99-avg-1.int8.onnx
            ├── decoder-epoch-99-avg-1.int8.onnx
            ├── joiner-epoch-99-avg-1.int8.onnx
            └── tokens.txt
```

未安装模型时，点 🎤 会提示「未找到语音模型」，其余功能不受影响。

## 与完整版的区别

| 功能 | 轻量版 | 完整版 |
|------|:------:|:------:|
| 多轮对话（流式输出） | ✅ | ✅ |
| 图片理解（上传 / 拖拽 / Ctrl+V 粘贴） | ✅ | ✅ |

轻量版不含 `torch`、`diffusers` 与 SD 模型（合计约 10.6 GB）。
文生图相关接口在轻量版中会返回"缺少依赖"提示，**不影响其余全部功能**。

## 使用步骤

1. **解压**主程序包到任意目录（建议路径不含空格）
2. （可选，用语音才需要）解压 `asr-model-zh-14M-int8.zip`，把 `asr_model` 放进 `_internal/`
3. **安装 Ollama**：https://ollama.com（或 `winget install Ollama.Ollama`）
4. **拉取模型**：
   ```bash
   ollama pull qwen3-vl:8b
   ```
   （约 6.1 GB，只需一次）
5. **双击 `本地多模态助手.exe`**，自动弹出独立桌面窗口（非浏览器）

> 🔒 完全本地离线运行，数据不出本机。
> 首次启动需数十秒；启动失败会弹窗提示原因，不会静默闪退。
