# 从镜像仓库部署（不用下载 27GB 交付包）

> 这套文件是**部署套件**：有了它 + 镜像仓库里的镜像，就能在任何装了 Docker 的机器上跑起来。

## 三步走

### 第 1 步：把这套文件取出来

如果你手上只有镜像、没有这些脚本，一条命令就能取出来
（在你想安装的目录里执行，比如 `D:\本地多模态助手\`）：

```cmd
docker run --rm -v "%CD%:/out" ccr.ccs.tencentyun.com/bendiai/multimodal-deploy:latest sh -c "cp -r /deploy/. /out/"
```

执行完这个目录里会有：

| 文件 | 用途 |
|---|---|
| **`一键部署.bat`** | ← **双击这个就行** |
| `compose.yml` / `compose.gpu.yml` | 编排文件（脚本会自己选用哪个） |
| `使用说明.md` | 完整使用文档（含每个功能怎么用） |
| `data/config.json` | 默认配置模板 |
| `查看状态.bat` / `停止运行.bat` / `完全卸载.bat` | 日常维护 |

### 第 2 步：双击 `一键部署.bat`

它会依次做这些事（**全自动，不需要你输任何东西**）：

1. 检查 Docker 引擎、磁盘空间、有没有 NVIDIA 显卡
2. **从镜像仓库拉应用镜像** —— 有 N 卡拉 GPU 版，否则 CPU 版
   （本地已经有镜像的话会跳过）
3. **拉取模型镜像并提取模型文件**到本地 `models\` 目录
   （约 18GB，第一次会久一点；这一步不做的话容器里没有模型，问什么都会报错）
4. 启动服务，等它就绪后自动打开浏览器：http://127.0.0.1:8000

### 第 3 步：等着就行

第一次总共要下载约 **25GB**：

| 内容 | 大小 | 说明 |
|---|---|---|
| 应用镜像（CPU 版） | 548 MB | 任何电脑都能跑 |
| 应用镜像（GPU 版） | 3.4 GB | 仅 NVIDIA 显卡会下载 |
| Ollama 运行时 | 9.2 GB | 模型推理引擎 |
| **模型** | **18 GB** | Qwen3-VL 8B（看图+对话）、Qwen2.5-Coder 14B（写代码）、SD-Turbo（绘图）、Real-ESRGAN（超分） |

下载时间取决于带宽。**下行通常很快（30 分钟内）**；如果你看到特别慢，
先用浏览器下个大文件测一下自己的实际下行速度。

## 镜像清单

| 镜像地址 | 说明 |
|---|---|
| `ccr.ccs.tencentyun.com/bendiai/multimodal-app:latest` | 应用（CPU 版） |
| `ccr.ccs.tencentyun.com/bendiai/multimodal-app:gpu` | 应用（NVIDIA GPU 加速版） |
| `ccr.ccs.tencentyun.com/bendiai/multimodal-ollama:latest` | Ollama 运行时 |
| `ccr.ccs.tencentyun.com/bendiai/multimodal-models:latest` | 全部模型（**数据镜像**，不是可运行的服务） |

> ⚠️ `multimodal-models` 不是拿来 `docker run` 的 —— 它只是"分发载体"。
> `一键部署.bat` 会自动用 `docker cp` 把里面的 `/models` 提取到本地 `models\` 目录。
> 手动提取的话是这两条：
> ```cmd
> docker create --name mm-tmp ccr.ccs.tencentyun.com/bendiai/multimodal-models:latest
> docker cp mm-tmp:/models/. .\models\
> docker rm mm-tmp
> ```

## 前提条件

- 装了 **Docker Desktop**
  （没装的话：https://www.docker.com/products/docker-desktop/ ，
  安装时保持默认选项，**务必用 WSL2 后端**）
- 磁盘至少留 **40 GB**（镜像约 13GB + 模型 19GB + 运行时余量）
- 有 **NVIDIA 显卡**体验会好很多；CPU 也能跑，但推理会明显慢

## 和"离线交付包"的区别

| | 离线包（27GB U 盘拷） | 从镜像仓库拉（本方式） |
|---|---|---|
| 首次准备 | 拷 27GB 文件 | 联网下载约 25GB |
| 后续更新 | 重新拷整个包 | `docker pull` 一下就更新了 |
| 适用场景 | 目标机器**没有网** | 有网、或者懒得拷贝 |
| 脚本 | 同一个 `一键部署.bat` 都能用 | 同左（它会自己判断走哪条路） |

> `一键部署.bat` 是**一套脚本两种模式**：
> 优先用本地 `images\*.tar`（离线包），没有才去镜像仓库拉。
