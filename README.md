# 本地多模态助手（本地多模态）

一个**完全本地、单机离线运行**的办公多模态 AI 助手，基于阿里开源 **Qwen3-VL-8B**。
支持：日常聊天、写作（周报/邮件/文案）、文章总结、图片理解。

> 🔒 **完全本地：数据不出机、免费、无任何外部 API 调用。**

## ✨ 功能

- 💬 多轮对话，**思考过程与回答边想边出**（不是等全部想完才一次性吐出来）
- ⏹ **随时终止**：发送键旁边有「■ 终止」，点了模型**真的会停下**（不占显卡），
  已生成的内容保留，不会白等
- 🖼 图片理解：上传/粘贴图片，自动描述或识别内容
- 🎤 **语音唤醒**：说「**小千小千**」或「**小千**」即可唤醒（同音字也能认，如「晓谦」），
  窗口自动弹到最前、**光标跳进输入框**并开始收音，**停顿 2 秒自动发送**，没说话就不发（完全离线）
  · **唤醒后有 10 秒等待时间**：喊完唤醒词"停一下再说"也不会错过（以前 2 秒就结束这一轮）
  · **自己看着自己**：监听线程万一退出（设备被独占 / 蓝牙断开）会自动重开；
    你自己点 🎤 关掉的不在此列（界面每 20 秒和后端对一次账，不一致会明说）
  · 能**选麦克风**、有**实时电平条**（喊不动时一眼看出是不是没采到声音）
  · 唤醒门槛**跟着环境底噪自适应**（安静房间更灵敏，嘈杂环境不误触发）
  · 识别用**中文专用模型**（实测字错率 3.8%，比中英双语模型的 17% 准得多）
- 📚 **知识库**：把资料丢进一个文件夹即可被检索（**无需导入**），**支持多层子文件夹**分类
  支持 **txt / md / csv / json / 代码 / pdf / docx / xlsx / pptx / xls / et**，
  模型会自己决定要不要查、要不要同时联网
- 📄 **拖拽文档给模型**：把文件拖到**窗口任意位置**都行（不是只能拖到输入框），
  **不限格式**（读不出会明确说明原因，不会没反应）；也可以用输入框左边的 📎 选文件，
  或者复制文件后 Ctrl+V 粘贴
- 🧠 **记忆（自动记，不用你说「记住」）**：每轮对话后台自己判断什么值得留下 ——
  身份、经历、技能、偏好、**目标计划**都会记；寒暄和一次性提问不记。
  目标还会**跟着进展自动改写**（说「考过了」会把「打算考」替换掉，不会攒出互相矛盾的两条）
  · 长期记忆（所有对话共享）+ 短期记忆（每个对话各一份，互不串味）
- 💻 **写代码 / 离线计算**：遇到写代码的需求自动换**专用代码模型**
  （qwen2.5-coder，不思考、比视觉模型稳得多）；开启「本地算代码」后，
  模型写完 Python 会在**本机真跑一遍**，用真实结果回答（临时目录）
- 📝 **代码可看、可改、可重跑**：模型跑过的代码、以及它写在回答里的代码块，
  都渲染成**代码卡片** —— 点「编辑」直接改，点「运行」立刻在本机跑出真实输出
- ⏱ **要一直跑的程序（计时器 / 服务器 / 游戏）不设时限**：点卡片上的「▶ 运行」
  会**边跑边出字**、随时能停（番茄钟、小服务器都能正常跑）。模型自己验证这类程序时
  只跑前几秒做**冒烟测试**，并明确说明「这不是报错、不要改代码」；
  一次性计算的时限可用 `run_timeout` 调整（默认 60 秒，可填 5~600）
- ⌨️ **要输入的程序能输入**：程序问到「请输入…」时，运行中的卡片下方会出现**输入框**，
  打字回车就送进去（一行对应一次 `input()`）；模型那一侧也能用 `stdin` 参数预喂输入
- 🛡 **危险操作先问你**：模型要删文件 / 起进程 / 联网时会弹框说明并把代码给你看，
  点「允许」才执行、点「拒绝」它就去换写法（**不是一律拒绝**）
- ✍️ **写作文 / 生成文档**：信息不够时**弹出问答框**问你用途/字数/文体（不用你在对话框里一条条回），
  然后按你的要求写；要文件就写进**生成文库**，还能**一键导出 Word**（WPS 直接打开）
- 🗂 **生成文库**（与只读知识库**分开**）：模型产出的作文 / 方案 / 报告 / 代码模块都放这里，**可用文件夹归类**，
  可查看、可编辑、可导出、可删除；覆盖前自动备份、删除进回收站
- 🧠 **意图推断**：你没明说的意图也会推断并记下来 —— 问「自考本科我能不能考？」
  → 记忆里出现「（推断）用户在考虑通过自考提升学历，正在权衡要不要报考」
- 🔧 **多工具并行**：同一轮里的多个工具并发执行，耗时只取最慢的那个
- 🎨 **本地绘图**：文生图 / 图片微改 / 超分，全程离线；有 N 卡时自动走显卡
- 📝 办公场景：写周报、邮件、文案、总结文章
- ⚙️ 可调参数：温度、上下文长度、最大生成长度（持久化保存）
- 📦 模型管理：一键检测、下载默认模型
- 🚀 可打包成单文件 exe 或 **Docker 一键部署包**

## ⚡ 快速开始（五步）

### 1. 安装 Ollama

方式一（推荐）：前往 https://ollama.com 下载安装包，双击安装。

方式二（命令行）：
```bash
winget install Ollama.Ollama
```

### 2. 安装 Python（若需从源码运行）

前往 https://www.python.org 安装 Python 3.10+，勾选 **Add to PATH**。

### 3. 安装后端依赖

```bash
python -m pip install -r requirements.txt
```

### 4. 下载模型（约 6GB，只需一次，之后完全离线）

```bash
ollama pull qwen3-vl:8b
```

### 5. 启动应用

```bash
python run.py
```
浏览器自动打开 `http://127.0.0.1:8000`。

---

也可以直接双击 `scripts/` 下的一键脚本：
- `setup.bat` —— 一键安装依赖
- `pull_model.bat` —— 下载模型
- `start.bat` —— 启动应用

## 🧩 打包为应用程序（exe）

```bash
cd build
build.bat
```
完成后生成 `dist/本地多模态助手.exe`，单文件、无需安装，复制到任意目录即可运行（仍需已装 Ollama 与模型）。

## 🐳 Docker 一键部署（离线包）

源码之外还提供一个**离线部署包**（与源码分开分发，约 26 GB，含全部模型与两个应用镜像）：

```
<包根目录>\
├── 一键部署.bat / 停止运行.bat / 查看状态.bat / 完全卸载.bat
├── 使用说明.md          ← 详细用法看这份
├── compose.yml / compose.gpu.yml / .env（脚本自动生成）
├── images\              离线镜像 tar        ★必需
├── models\              模型权重（对话 + 代码 + 绘图）★必需
├── data\                用户数据（可整体带走）
└── build\               构建上下文（可删）
```

双击 **`一键部署.bat`** 即可，脚本会自动：

1. 检查 Docker 引擎
2. 有 NVIDIA 显卡就叠加 GPU 编排
3. **探测宿主机是否已有 Ollama** —— 有就直连（零下载），没有才走容器自带
4. 镜像不存在就先从 `images\` 导入 tar（离线）
5. 启动服务、轮询健康检查、打开浏览器

> **镜像默认是 CPU 版 torch**（通用性优先，任何机器都能跑，约 2.4GB）。
> 想让**绘图**也吃显卡，用 CUDA 版重建（RTX 50 系必须 `cu130`，`cu124` 不行）：
> ```bash
> docker build -f docker/Dockerfile.app \
>   --build-arg TORCH_INDEX=https://download.pytorch.org/whl/cu130 \
>   -t local-multimodal-app:latest ./build
> ```
> 对话/看图走的是 Ollama，只要叠加 `compose.gpu.yml` 就已经在用显卡了。
> 界面右上角的徽章会显示当前是 `🖥 CPU 模式` 还是 `⚡ GPU 加速（显卡名）`。

⚠️ **本机同时跑源码版和 Docker 版会抢 8000 端口** —— 先关掉其中一个。

## 📚 知识库怎么用

三步，**不需要任何导入操作**：

1. 侧边栏「📚 知识库」面板 → 点「**📂 打开文件夹**」（路径直接印在面板上）
2. 把资料文件**拷进这个文件夹**，刷新即可看到 `xxx 字 · 可检索`
3. 打开界面顶部的「**知识库**」开关

之后提问涉及这些资料时，模型会**自己决定**要不要查 —— 它有两种方式：

| 机制 | 触发 | 作用 |
|---|---|---|
| 自动检索 | 每轮按相关度搜一次，**只在真命中时才注入** | 常见问题直接就带上了资料 |
| `search_knowledge` 工具 | 模型自己决定 | 可列目录、换关键词多查几轮 |

无关提问的相关度实测是 **0**，所以不会平白占用上下文。
系统提示里写明了**知识库优先于联网**，两者也能**同时用**：知识库答内部细节、网络补时效信息。

> 文件格式支持：txt / md / csv / json / 日志 / 代码 / **pdf** / **docx** / **xlsx** / **pptx** /
> **xls** / **et**（旧版 Excel、WPS 表格，自带解析）。
> 读不出文字的（如扫描版 PDF、旧版 `.doc`）会在面板里**明确标出原因**，
> 不会出现「文件放进去了、界面上却什么都没有」的情况。
>
> 以 `_` 开头的文件会被忽略（留给说明文件用）。

只想临时看一份文档，不想进知识库？**直接把它拖进聊天框**即可（和拖图片一样）。

## 🔧 参数说明

配置集中在 `config.json`（前端「推理参数」可在线修改并自动保存）：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `ollama_url` | `http://127.0.0.1:11434` | Ollama 本地服务地址。**别改成 `localhost`** —— Windows 上它会先解析到 IPv6 的 `::1`，而 Ollama 只监听 IPv4，每次连接都要白等一次回退超时（实测 2065ms vs 1ms）。代码里已会自动纠正 |
| `default_model` | `qwen3-vl:8b` | 默认推理模型 |
| `temperature` | `0.7` | 采样温度，越低越严谨 |
| `num_ctx` | `12288` | 上下文窗口。工具 schema + 系统提示固定占约 5000，低于 8192 会把历史/回答挤没。显存小的机器可调回 8192 |
| `max_tokens` | `4096` | 单次最大生成 token。Qwen3-VL 无法关闭思考，给太少会出现「思考到一半就断、正文一个字没写」 |
| `rag_enabled` | `false` | 知识库检索开关 |
| `web_enabled` | `false` | 联网搜索开关（默认关闭，打开才会联网） |
| `t2i_device` | `auto` | 绘图设备：`auto` / `cpu` / `gpu` |
| `voice_auto_start` | `true` | 启动时自动开麦监听（容器里没有麦克风，会自动跳过） |

> ⚠️ **改完 `ollama_url` / `num_ctx` 等参数需要重启服务**才完全生效；
> 其中 `num_ctx` 尤其要注意：**它和当前已加载模型不一致会触发重新加载**，
> 而重载会打断正在进行的生成（表现为「加载一半、思考一半、没有回答」）。

## 🛠 常见问题

**启动后浏览器无法连接 Ollama？**
确保 Ollama 已启动（任务栏有 Ollama 图标），或运行 `ollama serve`。

**模型未就绪？**
在界面「模型管理」中点击「开始下载」，或执行 `ollama pull qwen3-vl:8b`。

**显存不足？**
在 `config.json` 中调低 `num_ctx`（如 4096），或改用更小的量化模型。
